# Practical ML
Practical sessions of the course *Practical Introduction to Machine Learning* (M2 Data Science, École Polytechnique).
## Regression - ECoG signals
Predicting the thumb flexion of a subject from 64 ECoG electrodes (BCI Competition IV, dataset 4). Least squares (by hand and with scikit-learn), Ridge, Lasso, Random Forest, SVR, MLP and Gradient Boosting are compared. The Lasso gives the best test performance using only 14 electrodes out of 64.
